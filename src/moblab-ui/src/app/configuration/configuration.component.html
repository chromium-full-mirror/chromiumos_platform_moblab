Enable Moblab cloud integration
Cloud integration is necessary for Moblab to fetch Chrome OS test images as well as upload test results for CPCon ingestion. ( The boto and GCS bucket forms below are cloud configurations )
Changes to the Boto and GCS Bucket configuration are not allowed. Please powerwash the Moblab to update the account info.
After tests were ran with a given account updates to the account configuration are not allowed.
